# Seed Oracle 0.1.64

修复极速商店的随机升级目标规划。

## 修复

- 前置拿牌、删牌、变牌、升级和附魔会进入随机升级分支，最终牌库状态包含毒素之蛋、熔火之蛋、冻结之蛋等加入牌库钩子。
- “求购”页可以直接点击随机升级目标，例如“上勾拳+”，反向列出所有购买组合与具体选牌、跳过、删牌、变牌操作。
- 多屏奖励按货架来源和奖励组分段显示，强化牌名称统一只显示一个加号。
- 修复商店初始展开状态跳过首次计算，以及购买回调与重算重叠时的误报。

## 验证

- `blitz-random-deck-branches PASS`
- `blitz-transform-eggs PASS`
- `blitz-plan-panel PASS`
- `event-audit failed=0`
- Release 构建通过，安装文件哈希与发布文件一致。
