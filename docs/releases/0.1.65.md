# Seed Oracle 0.1.65

修复极速商店随机升级目标出现不可达选牌路径的问题。

## 修复内容

- 前置商品重放分别使用 `Shops` 和 `Rewards` 的实际推进量。“每种稀有度各一组牌”等奖励商品的候选牌与当前奖励流位置对应。
- 按实际购买顺序计算目标路径，并保留每组奖励的拿牌或跳过要求。多个愿望会检查同一奖励组的选牌是否冲突。
- 随机升级依照前置拿牌、删牌、变牌、升级和附魔后的牌库计算，条件结果附带具体操作。
- 状态指纹覆盖完整玩家状态，包括随机数流、遗物和卡牌状态。状态变化时立即清除旧预测，重算完成后显示新结果。
- 选牌分支上限调整为 4096。达到上限时明确提示当前显示部分路径。
- 购买审计在购买前保存预测参照，并记录购买前后的商店、奖励和变牌流计数。

## 验证

- 问题存档的 48 项商品结果对照通过。
- 两种前置购买顺序的 512 条选牌路径逐条完成原生购买回放，结果一致。
- 20 类商品直接预测与原生购买对照通过。
- 购买顺序、选牌冲突、随机数流失效及面板回归通过。
- 事件审计通过，`nondeterministic=0 failed=0`。
- 完整版和独立版的 Release 构建均为 0 警告、0 错误，安装文件哈希与构建文件一致。

本次游戏内界面操作仍由玩家重启游戏后测试。

## 独立极速商店版本

Blitz Shop Oracle 0.1.1 的源码与安装包通过 GitHub 提供，包含同一组修复。测试独立版时请关闭完整版 Seed Oracle，独立版检测到完整版已加载时会自动停用。
