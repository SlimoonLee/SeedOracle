# Seed Oracle 0.1.62

0.1.61 的 UI 修复轮，由悬停控件诊断（`[BlitzHoverDiag]`）定位。

## 修复

1. **页签点击范围**：窗口改挂 `NRun.GlobalUi` 并最后添加——Godot 的 GUI 点击判定按场景树顺序走（`ZIndex` 只影响绘制），`GlobalUi` 分支在树序中晚于房间分支，此前游戏顶栏吃掉了页签按钮上半部的点击（绘制在顶栏之上、命中被顶栏遮住，故用户只见"下方一点点可点"）。改挂后绘制与输入双优先，按钮整域可点。
2. **页签回标题行**：输入优先级修复后，页签回到标题行内由布局预留空间——正文说明不再被绝对定位的按钮遮挡；页签构造与物品 chip 同款（文字自适应宽、40px 高）。
3. 顺带修复标题行透明占位控件的鼠标过滤（改为穿透），标题过长时截断而不是压到按钮。
