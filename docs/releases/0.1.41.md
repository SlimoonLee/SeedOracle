# Seed Oracle 0.1.41

适配《杀戮尖塔 2》0.111.0。本次汇总自工坊 0.1.24 以来的修复。

- 核对原版商店生成、价格、半价、购买回调与送货员补货；前置事件、奖励和购买产生的实际变化以具体分支展示。已验证等效的普通拿牌、跳过与购牌合并说明。
- 补齐浮木、多组选牌、狩猎和熔岩灯重掷预测。区分完整与部分覆盖，未算到的组合保持未知，避免虚假的“卡牌消失”。
- 商店保留一份基础库存，其他情况只列变化格位与差价；变牌事件合并相同结果，保留实际来源张数。补齐帕尔之翼献祭、卡图附魔名称和数值。
- 加宽并分页长提示，Shift+滚轮翻页时锁定地图滚动；优化羽翼之靴路线剪枝、悬停缓存、快速划过节点和隐藏面板的计算开销。
- 修复预测锻造触发整副牌动画，保持真实跑局与预测副本隔离。
- 补齐巨口储蓄罐进房金币、永恒羽毛营地治疗、规划账本自动收益及致命事件加载后的问号赔率。

隔离回归、原版对照及 Release 构建通过，新增 72 种原版重掷预览对照。自动跑局已完成样本中的奖励、怪物生命和遭遇一致；两次长跑因 RitsuLib 动画节点异常中断，不计为完整跑局通过。复杂节点首次预测仍有计算开销，未宣称实际游玩全程无卡顿。

详见[本轮验证记录](../validation/extended-audit-2026-10-17.md)。

安装包：`SeedOracle-0.1.41.zip`，包含 DLL、PDB 与 Mod 清单；需启用 STS2-RitsuLib、RandomForeseer 和 CombatSolver。
