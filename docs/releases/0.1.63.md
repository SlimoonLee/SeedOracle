# Seed Oracle 0.1.63

新增极速模式地图浮窗预测。

## 新增

- **极速模式地图浮窗预测**：极速模式的跑内地图是顶部图标条（`NBlitzTopBarMap`），悬停未访问节点此前只有游戏自带图例提示。现在 `NBlitzTopBarMapPoint.OnFocus` 的 postfix 会把 Seed Oracle 预测面板**追加进游戏自带的悬停浮窗容器**：
  - "Seed Oracle · 预测"——该节点的遭遇与奖励掉落（战斗金币/卡牌组、极速商店货物、宝箱内容），复用 `MapForecastService` 全套预测（线性链上仅一条固定路径、走轻量分支；LRU 缓存 + LiveFingerprint 失效照常生效）；
  - "Seed Oracle · 后续先古与 Boss"——纯 Act 模型读取的摘要：当前幕 Boss（悬停节点本身是 Boss 时不重复）及后续各幕先古/Boss/第二 Boss。
- 相邻节点即时渲染，更远节点 80ms 延迟防快速划过连续计算；面板随 `OnUnfocus` 移除浮窗时一并释放。
- 已核实极速模式差异：特兹卡塔拉的池 3（黄金罗盘/南瓜蜡烛/玩具盒/黄金印）在极速被 `RelicLists.notAllowedInBlitz` 封禁，第三格从池 1+2 回填——预测走游戏自身生成逻辑（影子跑局携带 Blitz GameMode），封禁自动生效。

## 验证

- 自检新增 `BlitzMapForecastRegressionTests`：Blitz 影子跑局 + `BlitzActMap`，断言行 1 怪物节点遭遇与战斗奖励、行 3 商店的极速货物、行 5 宝箱内容、后续摘要覆盖 3 幕且含当前幕 Boss 与后续先古；门禁 58 项全 PASS。
