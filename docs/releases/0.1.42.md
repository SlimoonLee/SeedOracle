适配《杀戮尖塔 2》0.111.0。本次版本修复地图预测可能影响真实跑局的副作用。

- 影子事件角色死亡不再调用全局失败结算、删除真实存档或显示真实 Game Over；事件致死、蜥蜴尾巴、瓶中精灵和强制死亡仍按原版语义计算。

- 试炼的放弃跑局选项不会在事件探测时打开真实确认框，也不会被错误当作可继续的战斗分支。
- 新增死亡、商店删牌、阳伞、放弃跑局和全局边界回归；完整规划审计与事件审计通过，`event-audit SUMMARY: ok=105 degraded=16 nondeterministic=0 failed=0`。
