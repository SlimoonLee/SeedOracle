# Seed Oracle 0.1.59

自 0.1.42 以来的第 17 个版本，覆盖 0.1.43–0.1.59 共 16 次迭代。主线有三条：游戏 v0.113.0 适配与地图浮窗可读性、极速商店（Blitz）的完整预测体系、以及把整套预测从"影子真买"迁移到"随机数定位直生"。

## 极速商店：从"未建模"到"求购规划"（0.1.53–0.1.59）

- **货物与收益**：货架 6 件（5 加权 + 1 诅咒）逐项列出，悬浮直接写明买下会得到什么——三选一的每张牌、药水、遗物、诅咒点名；需要选牌的条目列出全部候选和逐候选结果（0.1.53/0.1.54/0.1.57）。
- **顺序机制**：实测每类条目对随机数流的推进量（卡牌奖励 +18、稀有 +9、药水 +4、遗物 +1 动遗物袋、诅咒条目各藏一张诅咒……），并证明**顺序无关性**——一件货物的内容只由"先买了哪几件"决定，与那几件的先后无关。
- **「全景与求购」窗口**（0.1.59）：进店自动打开。求购页按水晶球预测器的展示规则，把每件货物能给出的**具体物品**（每张牌、每瓶药水、每件遗物、诅咒）列为可点击的稀有度着色标签，悬浮显示物品自己的信息卡（费用/类型/完整描述）；点选即为"愿望"，窗口实时解算购买顺序（含只为推进随机数的"垫位"购买，垫位最少优先），无解时给出原因。全景页按相同结果合并列出所有"先买组合"的变化。
- **变化全覆盖**：变化表不只回答牌库已有的牌，也回答**先买卡牌奖励拿到的牌**与**诅咒货物送进牌库的诅咒**（诅咒→随机诅咒是真实规则），并列出"变化结果与路径"——每个结果 ← 全部来源（牌库／某件奖励屏／某件诅咒）。
- **性能与安全**：生成引擎改为**随机数定位直生**——克隆随机数流、按测得的偏移量跳位、在该位置调用游戏原生工厂；全程零购买执行（旧方案数百次影子购买曾导致进店卡顿与闪退），整架 96 行组合约 40ms 且与存档大小无关。店内悬浮保留购买探针并作为逐字一致性基准。

## 地图与浮窗（0.1.44–0.1.51）

- 适配游戏 v0.113.0（Blitz 模式、`AfterCardChangedPiles` 等）；宝箱按内容分组不再按路线分页；同一宝箱 22 条路线 → 7 页对应 7 种真实内容。
- 节点信息去重、奖励窗口只报结论、商店浮窗只留差价、求解器超时策略与预测显示优化；藏宝图宝箱 +600 金币与 Blitz 宝箱（2 遗物 0 金币）按游戏规则结算。

## 稳定性

- 修复影子预测可能影响真实跑局的副作用（0.1.42 线）延续：店内窗口的所有 UI 均挂主线程分片执行；悬浮信息卡按游戏 mega_text 层要求携带主题字体覆盖；窗口布局完成后自动夹回可视视口。
- 自检门禁从 0.1.42 的约 40 项扩至 **56 项**，新增极速商店全套（机制、顺序无关性、去重、求购解算、奖励/诅咒变化、面板渲染、直生与真买逐字 parity）。
