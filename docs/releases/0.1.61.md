# Seed Oracle 0.1.61

0.1.60 的闪退热修。崩溃定位：连续两家极速商店时，第二家进门后每次悬浮货物都会触发一次**全量跑局序列化+克隆购买**（0.1.54 的悬浮探针），实测日志显示玩家在商店内连续悬浮 10 次后进程原生消失（无托管异常、无 dump）。

## 修复

1. **悬浮改查表优先**：悬浮答案直接取自全景表——其 20 类条目与真实购买已逐字 parity 验证，查询零克隆零副作用、即时响应。探针降为兜底（窗口关闭/指纹过期等罕见情形）。
2. **全景未就绪时禁止探针**：商店进门到枚举完成的窗口期内悬浮显示"预测生成中……"，不再爆发式探针（每悬浮一次就是一次全量跑局往返——正是崩溃模式）。
3. 悬浮行附带同结果合并的"先买 X 后"提示（来自全景行，无探针）；能量徽章样式盒名称修正。

自检新增悬浮查表断言：表内命中行必须包含承诺内容、与真实购买探针逐字一致。门禁 57 项全 PASS。
